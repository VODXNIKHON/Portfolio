## ⚡ Core Architecture
This project is built with a focus on high-performance animations and seamless user experience.
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion 
* **Scroll Dynamics:** Lenis 
* **Icons:** Lucide React & Custom SVGs

## 🚀 Running Locally
To spin up this project on your own machine:

```bash
# 1. Clone the repository
git clone [https://github.com/VODXNIKHON/Portfolio.git](https://github.com/VODXNIKHON/Portfolio.git)

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
